# Electrum XRP

Electrum XRP is a desktop wallet for XRP on the XRP Ledger, available for Windows and Linux.

This repository is the home for the project's source code, documentation, and release information.

## Supported platforms

| Platform | Application |
| --- | --- |
| Windows | Desktop wallet |
| Linux | Desktop wallet |

## Downloads

Published builds and installation notes will be available on the [Releases](https://github.com/xrpl-devs/electrum-xrp/releases) page. Choose the package for your operating system and follow the instructions included with that release.

## Repository status

The repository currently contains project documentation. Wallet source code, build instructions, and release packages have not yet been added here.

## Feedback

Report bugs or suggest improvements through [GitHub Issues](https://github.com/xrpl-devs/electrum-xrp/issues). For application issues, include your operating system, wallet version, and steps to reproduce the problem.

Never include seed phrases, private keys, passwords, or wallet backup files in an issue.
